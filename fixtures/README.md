# Fixtures

Test data lives here. Two rules, both non-negotiable:

1. **We do not redistribute vendor data.** The METAS example project is used for
   verification but stays out of the repository — the installer's licence permits
   use and modification and forbids distribution to third parties. `git check-ignore`
   should refuse anything under `fixtures/vendor/`.
2. **Every fixture is described.** A file with no provenance note is not accepted,
   because a verification result is only as meaningful as its data.

## Layout

```
fixtures/
  synthetic/     generated by our own model; committed
  reference/     the Python prototype's outputs; committed (small text)
  vendor/        fetched locally, never committed
```

## Obtaining the METAS example project

It ships inside the public VNA Data Explorer installer. On a machine with Python:

```sh
python -m pip install pymsi
python -m pymsi extract metas_vna_data_explorer_setup_v3.0.2.msi -o /tmp/de
cp -r "/tmp/de/Commen Documents/Metas.Vna.Data.Explorer/Examples/01_Basic_Example_N(f-m)" \
      fixtures/vendor/metas-basic-example
```

That directory contains:

```
Measurements_01/   raw, uncalibrated measurements of every standard and DUT
SOLT_01_out/       the same measurements after VNA Tools' own SOLT calibration
FreqList_01.fl     the frequency list
```

The pair is the point: same raw data, reference answer. `tests/realdataset_test.cpp`
uses it when present and skips with an explanatory message when absent, so a fresh
clone still builds and tests.

## Expected values on that dataset

Recorded here so a regression is recognised as one, and so the test's expectations
are reviewable against the numbers that produced them. 191 points, 45 MHz–18 GHz,
20 dB attenuator, standard definitions approximated from the reference's own
corrected standards:

| quantity | expected |
| --- | --- |
| max abs ΔS21 versus `SOLT_01_out` | ≈ 2.8e-4 (|S21| ≈ 0.10) |
| rms ΔS21 | ≈ 7.4e-5 |
| median u(|S21|) claimed by the reference | 3.0e-4 |
| repeatability-only u ÷ reference total u | 0.008 at 70 MHz, 0.88 at 18 GHz |

An implementation that agrees much more closely than 1e-4 should be treated with
suspicion: it means the standard definitions were taken from the reference in a way
that makes the comparison circular.

## Hashes

Every committed fixture is listed in `fixtures/SHA256SUMS` with a one-line note.
Regenerating a fixture means updating the hash in the same commit, so a silent
change to test data is visible in review.
